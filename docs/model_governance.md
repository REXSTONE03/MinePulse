# MinePulse AI — Model Governance, Drift Monitoring & Retraining Framework

This document outlines the model governance, version control, Population Stability Index (PSI) drift monitoring, and automated retraining trigger framework implemented in MinePulse AI.

---

## 1. Governance Concept & Architecture

Every parts-ordering recommendation or vehicle risk estimate generated by MinePulse AI is traceable back to the exact version of the model, feature definition, training dataset, and hyper-parameter configurations that produced it.


## 2. Population Stability Index (PSI) Feature Drift Monitoring

Model monitoring computes Population Stability Index (PSI) across key component telemetry predictors to identify input distribution shifts between reference (training) and production datasets:

$$\text{PSI} = \sum_{b=1}^{B} \left( P_b - Q_b \right) \times \ln\left(\frac{P_b}{Q_b}\right)$$

Where $P_b$ is the actual production sample frequency in bin $b$, and $Q_b$ is the reference baseline frequency.

### Drift Score Interpretation Thresholds:
* **$\text{PSI} < 0.10$**: No distribution shift. Model continues in normal operational mode.
* **$0.10 \le \text{PSI} < 0.25$**: Moderate shift detected. Feature marked for close monitoring.
* **$\text{PSI} \ge 0.25$**: Significant distribution drift. Triggers an automated retraining signal.

## 3. Automated Retraining Trigger Logic

Retraining is controlled through explicit performance and drift evaluation rather than arbitrary background schedule polling:

```python
IF max_feature_psi >= 0.25 OR brier_score > 0.20 OR demand_mae > 6.0:
    STATUS = "RETRAINING_TRIGGERED"
    EVENT_ID = "RETRAIN_EVENT_<TIMESTAMP>"
    LOG_AUDIT_RECORD(event_id, trigger_reason, active_model_version)
```

The FastAPI endpoint `/api/v1/monitoring/trigger-retrain` allows authorized users (`ADMIN` or `MAINTENANCE_PLANNER` roles) to evaluate thresholds or issue manual retraining commands via the Model Governance UI dashboard.

---

## 4. REST API Endpoint Integration

* `GET /api/v1/monitoring/summary`: Returns active model metadata, Brier calibration, demand MAE, and active status.
* `GET /api/v1/monitoring/drift`: Returns per-feature Population Stability Index (PSI) breakdown and drift classification.
* `POST /api/v1/monitoring/trigger-retrain`: Evaluates conditions or forces an auditable retraining pipeline event.
